
# My Portfolio Website

A personal portfolio website built using Python and Django to showcase my profile, technical skills, resume, and contact information.

## About the Project

This is my personal developer portfolio project. It provides information about my professional profile, technical skills, and resume.

## Features

- Home page with personal introduction
- Dynamic profile and skills management
- Resume viewing and downloading
- Contact form
- Admin panel for managing portfolio information
- Staff dashboard

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript

## Project Structure

- `first_project/` - Django project configuration
- `portfolio/` - Main portfolio application
- `manage.py` - Django management file

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/jaiswaal-namrata/my-portfolio.git`

2. Open the project folder:

   `cd my-portfolio`

3. Install Django:

   `pip install django`

4. Run database migrations:

   `python manage.py migrate`

5. Start the development server:

   `python manage.py runserver`

6. Open in your browser:

   `http://127.0.0.1:8000/`
